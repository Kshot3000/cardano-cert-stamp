Stamp certificates

1. Network and wallet

Use a Cardano browser wallet (Lace, Eternl, Typhon…) set to the same network. For test networks, get free test ADA from the testnet faucet. You sign in your own wallet. This app never sees your keys or recovery phrase and never holds funds.

2. Issuer

3. Certificates

Columns: cert_no, recipient_name, course, date_awarded, optional grade, expires. Dates as YYYY-MM-DD. Other columns (like email) are ignored and never stored. Download a template.

4. Stamp

One transaction stamps the whole batch. Network fee is about 0.17–0.2 ADA from your own wallet. 1.5 ADA is sent back to your own address in the same transaction, so you only spend the fee. Stamping itself is free.
